# 启动程序 
## 比赛模式 
1. 比赛模式加入“崇武探幽”和“九宫藏宝”两个模式： 
2. “崇武探幽”模式： 选择该模式后，默认启动“武馆”和“梅林”两个区域，机器人从武馆的启动点出发，依次完成武器头拾取、武器组装、拾取KFS等任务。选择该模式后，需要选择相应半场（左右），默认开启状态机，串口通信功能，需自己输入KFS配置（真假），该模式下新增完成停止点（在完成任务后停下的坐标位置）：（x=-3。0, y=8.4, yaw=1.5708）,并加入180秒的比赛限时，180秒后自动停止（无论在进行什么任务）。
3. “九宫藏宝”模式： 选择该模式后，默认仅启动“对抗区”这一个区域，机器人从对抗区的启动点出发，依次完成放置KFS，与R1合体等任务。选择该模式后，需要选择相应半场（左右），默认开启状态机，串口通信功能，无需输入KFS配置，该模式下新增完成停止点（在完成任务后停下的坐标位置）：（x=-5.4, y=8.4, yaw=1.5708）,并加入180秒的比赛限时，180秒后自动停止（无论在进行什么任务）。
4. 比赛模式的全程模式不变 
5. 上面的坐标均是左半场的坐标，右半场的坐标为x轴对称，y轴不变即可。

## 新加入功能 
1. 新增半场对应的拾取武器头的坐标点，左半场拾取武器头的坐标点为WAYPOINT_WEAPON_RACK = {'x': -0.65, 'y': 0.95, 'yaw': 0.0}（目前已在config.py），武器组装点为WAYPOINT_ASSEMBLY = {'x': -0.65, 'y': 0.4, 'yaw': 3.1415}；右半场的拾取武器头的坐标点为WAYPOINT_WEAPON_RACK = {'x': 0.65, 'y': 1.25, 'yaw': 3.1415}，武器组装点为WAYPOINT_ASSEMBLY = {'x': 0.65, 'y': 0.4, 'yaw': 0.0}，在启动程序中选择半场后，程序根据选择的半场来选择对应的拾取武器头的坐标点和武器组装点。并且把这些参数写在config.py中，方便后续修改和维护。
